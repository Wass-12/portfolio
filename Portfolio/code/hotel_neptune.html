🌊 Hôtel Neptune

Application web de réservation hôtelière — Projet 2ème année BTS SIO SLAM

PHP 8.2 MySQL 8.0 Docker HTML / CSS Apache

Présentation du projet

L'Hôtel Neptune est une application web complète de gestion de réservations hôtelières développée en PHP natif avec une base de données MySQL. Le projet couvre l'intégralité du cycle : de la consultation des chambres par un client jusqu'à la validation par un administrateur, en passant par la génération automatique de factures. L'environnement de développement est entièrement conteneurisé avec Docker (PHP/Apache + MySQL + phpMyAdmin).

Fonctionnalités

👤 Espace client

  • Inscription et connexion sécurisée
  • Consultation des chambres avec filtres (type, vue, prix, dates, équipements)
  • Réservation en ligne avec calcul automatique du prix
  • Suivi des réservations (mes réservations)
  • Annulation d'une réservation

🛠 Espace administrateur

  • Tableau de bord avec statistiques
  • Gestion des chambres (ajout, modification, suppression)
  • Validation et annulation des réservations
  • Facturation automatique (HT, TVA, TTC)
  • Gestion des comptes utilisateurs

Base de données

Table Description Colonnes clés
users Clients et administrateurs id, email, password, nom, prenom, role
room_types Types de chambres (Standard, Suite…) id, nom, description, capacite, prix_nuit
rooms Chambres individuelles id, numero, type_id, etage, vue, wifi, minibar…
reservations Réservations des clients id, user_id, room_id, date_arrivee, date_depart, statut, prix_total
invoices Factures générées automatiquement id, reservation_id, montant_ht, tva, montant_ttc, statut

Lancer le projet

# 1. Cloner / extraire le projet
cd hotel_neptune

# 2. Démarrer les conteneurs Docker
docker-compose up -d

# Site web → http://localhost:8080
# phpMyAdmin → http://localhost:8081

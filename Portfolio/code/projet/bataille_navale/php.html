À propos du projet

Exercices d'algorithmique réalisés en PHP CLI dans le cadre du cours BTS SIO.


Le projet principal est une Bataille Navale en PHP pur :

  • Grille 10×10 initialisée avec des zéros
  • Placement interactif des navires (horizontal/vertical)
  • Vérification des collisions et dépassements
  • Affichage via affichetab()

D'autres exercices couvrent la logique conditionnelle, les boucles, les tableaux et le calcul numérique.


Techno : PHP 8.1 · CLI · Algorithmique pure
